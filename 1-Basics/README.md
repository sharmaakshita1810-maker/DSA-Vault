1-Basics <br>
This directory contains foundational concepts required before diving into Data Structures and Algorithms<br>
TOPICS COVERED :<br>
1. Input-Output : Standard stream operations ('cin','cout')<br>
2. Variables and Data types : Primitive datatypes used ('int' ,'float' ,'char' ,'bool') and ranges and sizes<br>
3. Operators : Arithmetic, Relational, Logical, Assignment and Bitwise operators<br>
4. Conditionals : Decision making using 'if', 'else if', 'else', 'ternary operators' and 'switch' statements
